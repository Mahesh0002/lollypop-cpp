## 2. Core Data Structures

All domain models are **plain C++ structs** (POD, no logic) defined in `include/types.hpp`:

```cpp
struct Track {
    std::string id;                 // UUID v4
    std::string title, artist, album, album_artist, genre;
    int track_number = 0, disc_number = 0, year = 0, duration = 0; // seconds
    std::string file_path;          // absolute path to audio file
    std::string artwork_path;       // cached artwork (local path or URL)
    std::string embedded_lyrics;    // raw lyrics from audio tags
    bool liked = false;
    int play_count = 0;
    int64_t last_played = 0, date_added = 0; // Unix timestamps
};

struct Album {
    std::string id, title, artist;
    int year = 0;
    std::string artwork_path;
    bool favorite = false;
    int64_t date_added = 0;
    std::vector<std::string> track_ids; // ordered
};

struct Artist {
    std::string id, name, artwork_path;
    int64_t date_added = 0;
    std::vector<std::string> album_ids;
};

struct Playlist {
    std::string id, name;
    bool is_smart = false;
    std::string smart_criteria; // SQL WHERE clause fragment
    int64_t date_created = 0, date_modified = 0;
    std::vector<std::string> track_ids;
};

struct Lyrics {
    std::string track_id, text, source;
    bool synced = false; // true = LRC format with timestamps
    int64_t updated_at = 0;
};
```

**ID Strategy**: All entities use UUID v4 strings (`lower_hex_randomblob(16)` in storage). This enables distributed sync and avoids integer collisions.

## 3. Storage Layer (`storage/`)

### `StorageManager` — SQLite Facade

**Key Design Decisions**:
- **Single-writer, multiple-readers**: Main thread writes; worker threads get read-only connections via `open_read_only_connection()` (RAII wrapper).
- **FTS5 for search**: Virtual table `tracks_fts` on `title, artist, album` with `content=tracks` for fast full-text search.
- **Triggers for denormalization**: `album_tracks` junction table + `albums`, `artists` aggregates maintained by triggers.
- **Schema versioning**: `PRAGMA user_version` + `migrate_schema(from, to)`.
- **Keyset pagination**: `get_tracks_paginated(limit, sort_key, last_sort_value, last_id, genre_filter)` avoids `OFFSET` overhead.

**Schema Highlights**:
```sql
CREATE TABLE tracks (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL, artist TEXT NOT NULL, album TEXT NOT NULL,
    album_artist TEXT, genre TEXT, track_number INTEGER, disc_number INTEGER,
    year INTEGER, duration INTEGER, file_path TEXT UNIQUE NOT NULL,
    artwork_path TEXT, embedded_lyrics TEXT, liked INTEGER DEFAULT 0,
    play_count INTEGER DEFAULT 0, last_played INTEGER DEFAULT 0,
    date_added INTEGER NOT NULL
);

CREATE VIRTUAL TABLE tracks_fts USING fts5(
    title, artist, album, content='tracks', content_rowid='rowid'
);

CREATE TABLE albums (
    id TEXT PRIMARY KEY, title TEXT NOT NULL, artist TEXT NOT NULL,
    year INTEGER, artwork_path TEXT, favorite INTEGER DEFAULT 0,
    date_added INTEGER NOT NULL
);

CREATE TABLE album_tracks (album_id TEXT, track_id TEXT, position INTEGER,
    PRIMARY KEY (album_id, track_id));
```

## 4. Backend Layer (`backend/`)

### `BackendController` — Central Orchestrator

Implements **all three service interfaces** (`IPlayerService`, `ILibraryService`, `ILyricsService`). Owns every subsystem:

```cpp
// Owned subsystems (unique_ptr unless shared)
StorageManager*           storage_;              // SQLite
AudioEngine*              audio_engine_;         // GStreamer pipeline
MprisManager*             mpris_manager_;        // External MPRIS player control
MprisServer*              mpris_server_;         // D-Bus MPRIS server (org.mpris.MediaPlayer2.lollypop)
LibraryScanner*           library_scanner_;      // Filesystem scanning + metadata extraction
LibraryManager*           library_manager_;      // Library mutation coordination
LyricsManager*            lyrics_manager_;       // Lyrics fetch/cache/sync
ArtworkManager*           artwork_manager_;      // Artwork download/cache
CacheManager*             cache_manager_;        // Metadata JSON cache (metadata_cache.json)
FileWatcher*              file_watcher_;         // inotify directory monitoring
CavaVisualizer*           cava_visualizer_;      // CAVA FFT spectrum
VisualizerEngine*         visualizer_engine_;    // Custom waveform/spectrum
QueueManager*             queue_manager_;        // Playback queue logic
PlaybackSourceManager*    playback_source_mgr_;  // Routes to AudioEngine or external MPRIS
```

#### **Playback Architecture**

```
┌─────────────────────────────────────────────────────────────────┐
│                    PlaybackSourceManager                        │
│  (Routes commands to active source, single active at a time)    │
├─────────────────────────────────────────────────────────────────┤
│  Internal Source (AudioEngine)     │  External Source (MPRIS)   │
│  ───────────────────────────────── │ ─────────────────────────  │
│  GStreamer pipeline:               │  Controls external player  │
│  filesrc → decodebin → audioconvert│  via D-Bus MPRIS           │
│  → tee → (audio sink + viz branch) │  (Spotify, VLC, etc.)      │
│                                    │                            │
│  Features:                         │  Features:                 │
│  • Gapless (preload next track)    │  • No local decoding       │
│  • Seek, volume, speed             │  • External playlist mgmt  │
│  • Visualization branch            │  • Unified UI controls     │
└────────────────────────────────────┴────────────────────────────┘
```

**Single Source of Truth**: `BackendController::playing_` (bool) is the **only** authoritative playback state. `AudioEngine` and `MprisManager` report state changes via callbacks; `BackendController` updates `playing_` through `set_playing(bool)` which:
- Guards re-entrancy with `changing_playback_state_`
- Emits `playback_state_changed_callbacks_` to all UI observers
- Syncs MPRIS server capabilities

#### **Queue Management** (`QueueManager`)

```cpp
// Data structures
std::deque<std::string> queue_;       // Main queue (track IDs)
std::deque<std::string> play_next_;   // "Play next" FIFO (drained first)
size_t current_index_ = 0;            // Cursor into queue_

// Shuffle: Fisher-Yates permutation of indices
std::vector<size_t> shuffle_order_;   // Rebuilt lazily on mutation
size_t shuffle_pos_ = 0;              // Position in shuffle_order_
bool shuffle_dirty_ = true;

// Repeat modes
enum RepeatMode { None, Playlist, Track };
```

**Navigation Logic**:
- `next_index()`: Drains `play_next_` first, then follows `shuffle_order_` or linear `current_index_`
- `previous_index()`: Reverse walk (respects shuffle history via `shuffle_history_` vector)
- Repeat `Track`: Returns same index; Repeat `Playlist`: Wraps at boundaries

#### **Library Scanning** (`LibraryScanner`)

```
scan_library(path)
    │
    ├─► Worker thread: walk directory (recursive)
    │     ├─ Extract metadata (TagLib: ID3, Vorbis, FLAC, MP4)
    │     ├─ Compute artwork (embedded → external fallback)
    │     ├─ Detect embedded lyrics (SYLT/USLT tags)
    │     └─ Batch INSERT into StorageManager (transaction)
    │
    ├─► Progress callbacks (files scanned, current file)
    │
    └─► On completion: invalidate caches, emit library_changed
```

**Incremental Scan**: `FileWatcher` (inotify) → `FileEvent` queue → `process_file_event()` → upsert/delete single track.

#### **Lyrics Pipeline** (`LyricsManager`)

```
request_synced_lyrics(track_id)
    │
    ├─ Check local DB (StorageManager)
    ├─ Check embedded tags (SYLT)
    ├─ Check metadata_cache.json
    ├─ Network providers (parallel, priority order):
    │     LRCLIB → MusicBrainz → Genius → NetEase → ...
    │
    ├─ On success: save to DB + cache, emit callback
    └─ On failure: return plain lyrics or "No lyrics"
```

#### **Artwork Pipeline** (`ArtworkManager`)

```
get_artwork_path_for_track/album/artist(id)
    │
    ├─ Local cache (~/.cache/lollypop-cpp/artwork/)
    ├─ Embedded artwork (extract from audio file)
    ├─ iTunes Search API (600px, high quality)
    ├─ MusicBrainz Cover Art Archive
    └─ Last.fm / Deezer fallback
```

### Application Entry Point

```cpp

    auto app = Application::create("org.gnome.Lollypop");
```

## 6. Data Flow

### Playback Initiation (User clicks track)

```
User clicks TrackRow in SongsPage
        │
        ▼
TrackRow::play_callback → MiddleLibrary → MainWindow → BackendController
        │
        ▼
BackendController::play_track(track_id)
        │
        ├─► QueueManager::set_queue({track_id}, 0)  // or play_tracks(vector, idx)
        │
        ├─► PlaybackSourceManager::play_current()
        │       │
        │       ├─ Internal: AudioEngine::load_track(path) → play()
        │       └─ External: MprisManager::Play()
        │
        ▼
AudioEngine callbacks (on GStreamer bus thread)
        │
        ├─► position_callback → BackendController::emit_position_changed
        ├─► state_callback    → BackendController::set_playing(bool)
        └─► eos_callback      → BackendController::next_track()
        │
        ▼
GLib::Dispatcher → GTK main thread
        │
        ├─► RightNowPlaying::update_playback_position()
        ├─► BottomPlayback::update_playback_position()
        ├─► PiPWindow::update_playback_position()
        └─► SyncedLyricsView::on_position_changed() (auto-scroll)
```

### Library Scan (Background)

```
BackendController::scan_library(path)
        │
        ├─► LibraryScanner::scan(path, progress_cb)  // Worker thread
        │       │
        │       ├─► TagLib metadata extraction
        │       ├─► StorageManager::insert_tracks_batch() (transaction)
        │       └─► progress_cb(files_done, total_files)
        │
        ├─► ScanProgress dispatched via Glib::Dispatcher
        │
        └─► On completion:
                ├─► invalidate_read_caches()
                ├─► emit_library_changed()
                └─► MiddleLibrary::refresh_active_page() → page->refresh()
```

### UI State Sync (Observer Pattern)

All UI panels register **multicast callbacks** on `BackendController`:

```cpp
// In MainWindow::connect_backend()
backend->add_track_changed_callback([this](const Track& t) {
    right_now_playing->update_track_info(t.title, t.artist, t.artwork_path);
    bottom_playback->update_track_info(t.title, t.artist, t.artwork_path);
    pip_window->update_track_info(t.title, t.artist, t.artwork_path);
});

backend->add_position_changed_callback([this](double pos, double dur) {
    right_now_playing->update_playback_position(pos, dur);
    bottom_playback->update_playback_position(pos, dur);
    pip_window->update_playback_position(pos, dur);
    // SyncedLyricsView auto-scrolls via its own callback
});

backend->add_queue_changed_callback([this](const auto& queue) {
    right_now_playing->set_queue(queue);
});
```

## 7. Threading Model

| Thread | Responsibility | Communication |
|--------|----------------|---------------|
| **Main (GTK)** | UI, event loop, GLib main context | All callbacks marshalled here via `Glib::Dispatcher` |
| **Scanner** | `LibraryScanner::scan()` | `Glib::Dispatcher` → `dispatch_scan_updates()` |
| **File Watcher** | `inotify` events | `FileEvent` queue + `Glib::Dispatcher` → `dispatch_file_events()` |
| **Lyrics/Artwork** | Network I/O (libcurl) | Background workers + `Glib::Dispatcher` for results |
| **AudioEngine** | GStreamer bus callbacks | Thread-safe queues → `Glib::Dispatcher` |
| **CAVA/Visualizer** | FFT processing | Ring buffer + `Glib::Dispatcher` for UI updates |

**Synchronization Primitives**:
- `std::mutex` for shared data (`queue_`, caches, pending events)
- `std::atomic<bool>` for flags (`scan_running_`, `playing_`, `workers_alive_`)
- `Glib::Dispatcher` for cross-thread → main thread marshalling
- RAII `ReadOnlyConnection` for SQLite read-only access

## 8. Key Design Patterns

### 1. Interface Segregation (Dependency Inversion)
```cpp
// UI depends on abstractions, not concretions
class MiddleLibrary {
    ILibraryService* library_service_;  // Not BackendController*
    // ...
};
```
Enables: testing with `MockLibraryService`, swapping storage backends.

### 2. Observer / Multicast Callbacks
```cpp
// Multiple panels can observe the same event
backend->add_track_changed_callback(cb1);
backend->add_track_changed_callback(cb2);
// Both called on track change
```

### 3. RAII for GTK Widget Safety
```cpp
// safe_gtk.hpp — prevents double-parent/unparent crashes
void safe_list_box_remove_all(GtkListBox* box) {
    // Collect children FIRST, then remove (avoids invalid sibling ptrs)
    std::vector<GtkWidget*> children;
    for (GtkWidget* c = gtk_widget_get_first_child(box); c; c = gtk_widget_get_next_sibling(c))
        if (GTK_IS_WIDGET(c)) children.push_back(c);
    for (GtkWidget* c : children) gtk_list_box_remove(box, c);
}
```

### 4. Lazy Page Construction
```cpp
void MiddleLibrary::ensure_page(const std::string& page_id) {
    if (pages_.contains(page_id)) return;
    // Construct only when navigated to
    if (page_id == "albums") pages_["albums"] = make_unique<AlbumsPage>(...);
    // ...
}
```

### 5. Keyset Pagination (SongsPage)
```cpp
// No OFFSET — uses last_seen (sort_key, id) for O(1) next page
std::vector<Track> get_tracks_paginated(limit, sort_key, last_sort_value, last_id, genre_filter);
```

### 6. Single Source of Truth (Playback State)
```cpp
// Only BackendController::set_playing() writes playing_
// AudioEngine/MprisManager callbacks ONLY notify
void on_audio_engine_state_changed(AudioEngine::PlaybackState state) {
    if (!changing_playback_state_) {
        set_playing(state == AudioEngine::PlaybackState::Playing);
    }
}
```

## 12. Extension Points

| Extension | How |
|-----------|-----|
| **New lyrics provider** | Implement in `LyricsManager::fetch_from_*()`, add to provider chain |
| **New artwork source** | Add method to `ArtworkManager`, wire into fallback chain |
| **New library page** | Subclass `LibraryPage`, register via `MiddleLibrary::register_page()` |
| **New playback source** | Implement `PlaybackSource` interface, register with `PlaybackSourceManager` |
| **Smart playlist criteria** | Extend `StorageManager::rebuild_smart_playlists()` SQL generator |
